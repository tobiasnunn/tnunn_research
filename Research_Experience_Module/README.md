# ENS-2002 Research Experience Module

This repo contains the code used in my Research Experience Module at[Bangor University](https://www.bangor.ac.uk/sens). My end of project portfolio can be found in '/Research_Experience_Module/07_portfolio'.

The research is based on a set of fasta files. Some from samples collected at Bangor University and others from the [NCBI](https://www.ncbi.nlm.nih.gov/). These are not stored in the repo due to their size.

The research was carried out from July 2024 to May 2025, the lab notebooks can be found in '/Research_Experience_Module/09_Notebooks'.
